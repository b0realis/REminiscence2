# Editor workshop

This two-room project demonstrates a sliced whole-level background, independent
foreground railing, a paired door/activator, a health pickup and a climbable
platform. The two PNG images were drawn for this project by
`tools/create_editor_example.py`; they contain no original Flashback artwork.
The example JSON, images and generator are GPL-3.0-or-later.

Use `./edit-local.sh` from the repository to create and open a private working
copy. Choose your prepared original assets to play. Walk right, press Enter
beside the orange activator, and continue into the room on the right. Approach
the raised platform and press Up to climb.

Read `docs/LEVEL_EDITOR.md` for the complete guide. Share the project and its
`art/` directory together, without your original game files.
