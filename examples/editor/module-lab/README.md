# Module Lab

An original three-room demonstration of the visual module editor. Its schematic
art, dialogue and project data are GPL-3.0-or-later; no Flashback artwork is included.
Regenerate with `python3 tools/create_module_workshop.py OUTPUT_FOLDER`.

Launch a private editable copy with `./edit-local.sh --modules`, then press PLAY:

1. Enter at the wall button opens the first door. Enter again toggles it closed.
2. Walk over the gold signal module, then Enter beside the technician. Read the
   dialogue and press Enter to continue. The second door unlocks.
3. Enter at the mission terminal to accept the job, then Enter at the orange
   power switch. Completion opens the final door. The switch may also be used
   before acceptance; the terminal remembers that objective.

Escape returns to editing. Select a part and choose **EDIT MODULE GRAPH**. Edit
connections, dialogue, requirements, animation strips and independent part rooms.
Original Amiga, DOS/GOG or Sega CD assets are needed only for the player playtest.
