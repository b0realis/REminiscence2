All WAVs are stereo signed 16 LE PCM, 44100 Hz, with stored pregaps removed.
`reminiscence2-segacd.json` is generated metadata, schema 1, not an original game
file. It holds SHA256 hashes for all extracted files/WAVs and the source CUE.
The inventory is descriptive, not a second hard-coded runtime directory.
