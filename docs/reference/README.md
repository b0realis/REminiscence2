# REminiscence2 research index

Project-written notes for understanding game formats and edition behavior.

- [Technical format notes](technical/README.md): the polygon cutscene player
  and 3DO edition differences, with links to the relevant engine source.
- [Protection settings](copy-protection/README.md): configuration for the
  original challenge screens, using documentation supplied by the player.
- [Player field guide](../../manual.md): original REminiscence2 instructions,
  controls, saves, presentation settings and tools.
- [Artwork preservation record](artwork/README.md): provenance of the privately
  retained graphic; the graphic itself is not distributed.

The supplied PDFs, protection sheets, artwork and superseded manual conversion
are held only under ignored `.local/reference/restricted/` storage. No
redistribution grant was supplied for those files. They are excluded from
public documentation and source archives; the engine's GPL does not relicense
them. The [documentation note](../manual/README.md) records the new guide's
scope and the removal of the earlier conversion.
